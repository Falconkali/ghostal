# UI/UX Pro Max Skill

## Description
AI-powered design intelligence database containing 84 UI styles, 192 color palettes, 74 font pairings, 98 UX guidelines, and 25 chart types across 22 tech stacks.

## Usage Guidelines
When designing or auditing UI/UX components:
1. **Design System & Palette Selection**: Select color palettes with proper contrast ratios and HSL tailwind configuration.
2. **Typography Pairings**: Pair primary display fonts with clean body fonts.
3. **UX Guidelines**: Enforce touch targets (min 44px on mobile), dark mode support, accessible contrast ratios (WCAG AAA/AA).
4. **Interactive States**: Include hover, active, focus, disabled, and loading states for all components.
